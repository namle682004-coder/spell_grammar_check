# Repository Guidelines & Agent Rules

## 1. Professional Tone & Code Integrity
- **No Conversational Filler in Files:** Never append chat-like questions, conversational pleasantries, or assistant filler phrases to code, documentation, scripts, commits, or READMEs (e.g., forbidding phrases like "Bạn có muốn tôi...", "Muốn tao viết luôn...", "Do you want me to...", "Let me know if you need...").
- **Strict Professional Register:** All documentation, comments, and commit messages must use a formal, technical, and objective engineering tone. Never use informal pronouns or colloquialisms (e.g., strictly prohibit "mày", "tao").
- **No Unsolicited Question Endings:** Do not end generated files or documentation sections with open-ended or rhetorical questions. Provide complete, actionable content directly.

## 2. Engineering Standards
- Follow standard software engineering best practices: Clean Architecture, PEP 8 / Ruff formatting, comprehensive error handling, and structured logging.
- Maintain documentation integrity: do not fabricate features, metrics, or credentials.
